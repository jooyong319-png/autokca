## 🔴 지금 병목 — 커뮤니티 시딩

**코드 쪽은 사실상 끝났다. 남은 건 트래픽이다.**

지금 질문당 0~1표라 화면에 "1명 참여"만 뜬다. 점선 도장 자리와 통계 줄을 넣었어도
숫자가 없으면 여전히 비어 보인다. 그리고 색인 임계치(표 20 + 댓글 1) 때문에
**모든 질문 페이지가 `noindex`다** — 검색 유입 경로가 없다.

이건 설계대로다. 순서가 이렇다:

```
시딩 → 표가 쌓임 → noindex 자동 해제 → 색인 → 검색 유입
```

- [ ] 🔴 **지인·단톡방으로 질문당 20~30표 확보.** 하루면 된다.
      임계치를 넘기면 막대가 나오고 사이트 인상이 완전히 달라진다.
      ⚠️ **가짜 표는 절대 넣지 않는다** — 약관에 "집계는 실제 투표 수"라고 명시했다
- [ ] 🔴 **커뮤니티 시딩**(브리프 §8) — 디시·인스티즈·더쿠·블라인드·에타에
      논쟁이 터질 질문 하나 + 링크. 주 2~3회.
      **시딩용 질문은 아껴둔다** — "확실히 터진다" 싶은 것을 남겨서 투입한다
- [ ] GSC · **네이버 서치어드바이저** 등록.
      코드는 안 고쳐도 된다 — `GOOGLE_SITE_VERIFICATION`·`NAVER_SITE_VERIFICATION`
      환경변수만 넣고 재배포하면 meta 태그가 생긴다

## 확인 못 한 것
